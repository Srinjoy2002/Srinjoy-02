SLAMDrive UAV

Engineered an autonomous UAV leveraging RetinaNET for weed detection in potato farms (89% accuracy) and human surveillance (97% accuracy) using real-time image processing and mapping. Devised a custom aerodynamic compensation algorithm via the AirSim Python API, optimizing fertilizer dispersal in windy conditions and achieving 97% path traversal rectification accuracy. Simulated complex operational environments using AirSim and ROS2 to validate real-time performance. Integrated Dijkstra’s algorithm and the Bendy Ruler technique for efficient path planning, incorporating Hector SLAM for dynamic mapping and obstacle avoidance, and programmed automated takeoff, landing, and Return-to-Home (RTH) functions.

LSTM-RNN based Emotion Detection System

Engineered a comprehensive preprocessing pipeline using ICA for artifact removal, bandpass/notch filtering, and min-max normalization to significantly enhance EEG signal quality. Constructed and optimized an LSTM-RNN model for real-time emotion recognition, achieving 90.9% test accuracy on the SEED-IV dataset by leveraging temporal EEG dependencies and fine-tuning hyperparameters with TensorFlow/Keras.
