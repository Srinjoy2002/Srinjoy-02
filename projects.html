01 / MACHINE VISION + CONTROL

Deep-Learning Driven
3D Profilometer

TensorFlowOpenCVOpen3DEtherCATPython

An integrated system for surface reconstruction using automated Z-axis traversal, synchronized imaging, attention-based focus segmentation, closed-loop stage control and variance-weighted focus stacking.

Reported project metrics: 0.92 mIoU for focus-region segmentation, 45 ms inference, ±0.1 µm closed-loop positioning accuracy and <0.8 µm reconstruction RMSE. These are project-reported figures, not independently benchmarked results.
